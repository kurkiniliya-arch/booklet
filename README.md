# Книга проектов

Приложение для Windows: фиксированное окно в форме пиксельной книги и личные задачи из хранилища Obsidian. Длинные списки прокручиваются внутри страниц, размер книги не зависит от содержимого.

- **Проекты:** раскрывающийся список, описания, создание, редактирование и удаление задач, отметка срочности.
- **История:** история по датам, фильтры и отмена ошибочной отметки.
- **Календарь:** месяц и задачи выбранного дня; запланированная дата отличается от крайнего срока.
- **Доска:** верхняя страница — все открытые задания, нижняя — только выбранные карточки в колонках «Сделать», «В процессе», «Сделано». Добавление кнопкой «На доску» или перетаскиванием; убрать карточку можно без изменения статуса, дат и истории задания.
- Цветные закладки над книгой переключают разделы. У доски страницы расположены сверху и снизу, с горизонтальным корешком; текст остаётся прямо, размер окна не меняется.
- Закрытая обложка, книжная иконка, сохранение данных между запусками.

Первое подключение: выберите папку хранилища Obsidian. Приложение работает с локальными файлами и не требует открытого Obsidian или MCP-сервера. Поле настройки повторения в редакторе отсутствует; существующие повторяющиеся задачи сохраняют своё правило и историю отдельных выполнений.

## Хранение

Задания читаются из Markdown. Флажки и постоянные блоки `^task-ID` сохраняются; описания задач, статус процесса, срочность, даты и признак `onBoard` хранятся в `task_details`. Выбор для доски независим от статуса: при первом открытии задания остаются в общем списке, пока пользователь сам их не выберет. Группировка и история приложения находятся в `90 Система/Quest Book.json`. Новые заметки создаются внутри папок проектов в корне хранилища.

Приложение перечитывает внешние изменения. Если заметка изменилась во время редактирования, устаревшее сохранение отклоняется; черновик остаётся доступным для согласования изменений. Неизвестные даты старых выполнений не подменяются сегодняшней датой.

Перед записью сохраняется резервная копия изменяемых файлов вне хранилища, в пользовательской папке приложения `backups`. Удаление группировки не удаляет исходные заметки с материалами; удаление задания затрагивает его запись, а не весь документ. Скрытые папки, настройки/ключи плагинов и текущие рабочие проекты исключены из импорта.

Личные данные, настройки подключения, снимки экрана и сборки не входят в Git. Репозиторий содержит только приложение и обезличенные проверки.

## Разработка

Нужен Node.js 24 и Windows для сборки Windows-приложения.

```sh
npm ci
npm start
npm test
npm run build
```

Если политика npm отключила загрузку Electron на этапе установки:

```sh
node node_modules/electron/install.js
```

`npm run build` создаёт переносимый EXE в `dist`. Для распакованной сборки: `npm run build:dir`.

После сборки `powershell -ExecutionPolicy Bypass -File scripts/install-local.ps1 -Launch` устанавливает приложение в пользовательскую папку Programs и создаёт ярлыки на рабочем столе и в меню «Пуск». Для обновления сначала закройте приложение. Личные настройки и хранилище при установке не удаляются.

Интеграционная проверка с Playwright запускается командой `node test/e2e.cjs` и использует отдельное временное хранилище. Если Playwright установлен не в проекте, его каталог можно передать через `NODE_PATH`.

Командная строка для начальной настройки: `--vault <папка>`. Для миграции существующей структуры поддерживается локальный `--bootstrap <JSON>`, который применяется только при первой инициализации. Личный bootstrap не следует добавлять в Git.

## Техническая основа

Electron с изолированным renderer, локальным протоколом, ограниченным IPC и без выполнения кода из заметок.

Иконка книги с пером и разворот используют оригинальные элементы из официального набора Mojang, как на образцах пользователя. Они скачиваются при подготовке сборки; Git содержит ссылки на фиксированную версию и контрольные суммы. `npm run prepare:assets` готовит их отдельно; запуск и сборка также выполняют этот шаг автоматически. Условия текстур сохранены в `src/renderer/assets/LICENSE-Mojang.md`. Тонкий пиксельный шрифт GNU Unifont с кириллицей поставляется локально по OFL; лицензия находится рядом с файлом шрифта.
