# Bundled typeface

`Unifont.otf` is the unmodified GNU Unifont 18.0.01 font from the official
[Unifoundry release](https://www.unifoundry.com/unifont/index.html).
It is bundled locally so the application does not request a remote font.

The bundled file's Unicode character map was checked for the complete Russian
alphabet, including `ё` and `Ё`, and all ten digits. All are present. Its
regular 8 × 16 pixel cells provide the thin pixel lettering used for the book;
16 CSS pixels align one font pixel with one screen pixel at 100% scaling.
Use normal weight and disable synthesized bold to preserve thin strokes.
